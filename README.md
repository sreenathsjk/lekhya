## ✨ What is DocDost?

**DocDost** (meaning "Document Friend" in Hindi) is a free, browser-based AI tool that acts as your personal expert — combining the knowledge of a lawyer, doctor, financial advisor, and chartered accountant — to help you understand any document and know exactly what to do next.

No jargon. No confusion. Just clear, actionable guidance.

## ⚡ Quick Deploy

### Step 1 — Get Free Gemini API Key
1. Go to [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. Sign in with your Google account
3. Click **"Create API Key"**
4. Copy the key (starts with `AIza...`)

### Step 2 — Deploy to GitHub Pages
1. Fork or upload `index.html` to a new GitHub repository
2. Go to **Settings → Pages**
3. Set Source to **Deploy from branch → main → / (root)**
4. Click **Save** — your site is live in ~2 minutes

### Step 3 — Use It
1. Open your live URL
2. Enter your Gemini API key when prompted
3. Upload a document or type a question
4. Get instant expert analysis!

## 🔐 Privacy & Security

- ✅ Your documents are sent **directly** from your browser to Google's Gemini API
- ✅ Your API key is stored **only in your browser's localStorage**
- ✅ **No server** — there is no backend, no database, no data collection
- ✅ Documents are **never stored** anywhere — processed in real-time only
- ✅ You can clear your API key anytime by clearing browser storage

## 🧠 How the AI Works

DocDost uses a carefully crafted system prompt that instructs Gemini to respond as a combined expert:

For every document it provides:
1. **Document identification** — what type of document it is
2. **Plain language summary** — key points anyone can understand
3. **Risk assessment** — Critical / High / Medium / Low
4. **Action steps** — exactly what you need to do next
5. **Deadlines & red flags** — highlighted clearly
6. **Jargon explained** — all technical terms in simple words
7. **Your rights** — under Indian law or relevant jurisdiction
